데이터 내보내기

현재 할 일, 일정, 용돈, 물품, 장보기, 습관 기록을 JSON 파일로 저장해. 다른 기기로 옮길 때도 사용할 수 있어.

데이터 가져오기

이 앱에서 내보낸 JSON 파일을 선택해. 가져오면 현재 데이터가 백업 파일의 데이터로 교체돼.

저장 공간

저장 정보를 확인 중이야.

초기화는 되돌릴 수 없어. 필요한 데이터는 먼저 백업해 줘.

사용 안내

  • 데이터는 현재 브라우저의 로컬 저장 공간에 보관돼.
  • 브라우저 데이터 삭제, 시크릿 모드, 다른 브라우저 사용 시 데이터가 사라지거나 보이지 않을 수 있어.
  • 다른 기기와 자동 동기화되지는 않아. 백업 파일을 직접 옮겨서 가져와야 해.
  • 이 앱은 외부 서버나 API를 호출하지 않아.
